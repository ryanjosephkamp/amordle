Why a migration is mandatory

The public game table recognizes all relevant source kinds, but the private authority table permits only ranked_queue and daily_lobby. Public Practice, private accepts, and rematches therefore still create legacy answer-bearing browser projections. Ranked Daily status/finalization exposes raw participant identity. React-only masking would not repair the server authority or privacy boundary.

Minimum additive change

  1. Extend private source authority to public lobby, private request, and rematch.
  2. Create/finalize those games through idempotent security-definer RPCs.
  3. Return only existing sanitized participant projections.
  4. Replace Ranked Daily status with player-relative data and opaque identifiers.
  5. Permit spectation only for active/completed public unranked Practice.
  6. Retain existing commands, clocks, terminal settlement, ratings, and request tables.
