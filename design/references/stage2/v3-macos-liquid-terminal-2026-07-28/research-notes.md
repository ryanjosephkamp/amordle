# Reference Classification

## Technical authority

### Apple Human Interface Guidelines — Materials

Source:
`https://developer.apple.com/design/human-interface-guidelines/materials`

Binding interpretation:

- Liquid Glass establishes a distinct control/navigation layer.
- It must not become the default content material.
- Regular glass is preferred where text and legibility matter.
- Clear glass is not required for Amordle.
- Use is sparse, functional, adaptive, and accessibility-aware.

### Apple Human Interface Guidelines — Typography and Fonts

Sources:

- `https://developer.apple.com/design/human-interface-guidelines/typography`
- `https://developer.apple.com/fonts/`

Binding interpretation:

- SF Pro is the native macOS interface voice.
- SF Mono is the native monospaced/coding voice.
- Web implementation uses system stacks and does not redistribute font files.
- Interface typography remains flat and readable rather than optically 3D.

### Apple Terminal profile behavior

Source:
`https://support.apple.com/guide/terminal/change-profiles-text-settings-trmltxt/mac`

Binding interpretation:

- Terminal supports font, background opacity, blur, cursor, selection, and ANSI
  color choices.
- Amordle borrows the relationship between monospaced content, translucent
  window material, cursor, selection, and restrained semantic color.
- The inspected local Basic profile resolves to `SFMono-Regular`.

## Structural reference

### Grok Build

Sources:

- `https://x.ai/cli`
- `https://docs.x.ai/build/overview`

Binding interpretation:

- full-screen, mouse-interactive TUI;
- compact path/context line;
- prompt marker and visible selection;
- dense aligned task/transcript rows;
- restrained shortcuts and footer help;
- minimal ornamental chrome.

Not copied:

- xAI/Grok name, logo, ASCII mark, wording, palette values, layouts, plugins,
  code samples, or distinctive trade dress.

## Mood references

- macOS window integration;
- Terminal’s focused work surface;
- quiet cool desktop backplates;
- subtle lensing and luminosity at functional glass edges.

Mood is not permission to copy Apple wallpapers, SF Symbols, application icons,
or proprietary assets.

## Anti-references

- Quiet Workbench’s flat ruled web-workspace appearance;
- generic SaaS cards and dashboard metrics;
- glassmorphism applied to every panel;
- cyberpunk, neon, Matrix/code rain, scanlines, CRT distortion;
- terminal cosplay that hides ordinary controls;
- dark-only styling;
- Apple or xAI visual cloning.
