# Rejected v3 Directions

## Quiet Workbench restyle

Rejected because recoloring the existing ruled panels and swapping the font
would preserve the scaffolding-like layout the v3 redesign exists to replace.

## Full-glass dashboard

Rejected because nested translucent cards flatten hierarchy, reduce text
contrast, increase rendering cost, and conflict with the functional material
boundary.

## Pure Grok-style fullscreen terminal

Rejected because it would under-deliver the explicit macOS and Liquid Glass
request and could make the game less approachable to non-terminal players.

## macOS productivity app with light terminal accents

Rejected because generic native-form styling alone would not make gameplay
feel like a convincing TUI.

## Dark-only terminal

Rejected because Amordle follows system appearance and must retain equal-quality
light mode.

## Fake interactive shell

Rejected because requiring typed commands, showing fabricated logs, or turning
routes into terminal syntax would make styling obstruct comprehension.

## Apple/xAI clone

Rejected because the work may use structural and technical reference but may
not copy protected assets, wording, logos, wallpapers, icons, or distinctive
trade dress.

## Decorative terminal effects

Rejected: scanlines, CRT bloom, code rain, glitch, typewriter page loads,
blinking text outside a real cursor, excessive glow, fire/ice, and cyberpunk
atmosphere.
