  scannable structure while preserving session semantics and mobile behavior.
- `ANNOT-03`, `ANNOT-04`, `ANNOT-07`, `ANNOT-09`: establish one systemic,

  all route-level contradictions.
- `ANNOT-05`: equalize Players filter input/select/action heights and baselines.

  layout overhaul using only durable or explicitly pending data; unambiguously
  represent every actual ranked lane.

  Escape, backdrop dismissal, focus, scroll lock, and pending-operation policy
  without converting anchored menus/tooltips into modals.
- `ANNOT-10`: route ordinary successful sign-in to Home while preserving only
  intentional, safe protected-route returns and recovery/verification flows.
- `ANNOT-11`: label the Account trigger using current player name, bounded
  owner-only fallback, or guest without overflow or cross-account flash.
- `ANNOT-12`: guarantee that every already-authorized rendered definition names
  its word in the same region without widening answer disclosure.

Whole-product audit scope:

- all application routes and reusable shell/control primitives;
- responsive states from 320 through 1920 CSS pixels and 200% zoom;
- light/dark system schemes, all named/custom accents, forced colors, reduced
  motion, print where relevant, keyboard, mouse, and touch;
- empty/loading/partial/offline/error/success/pending/disabled/terminal states;
- accessibility, copy, information hierarchy, performance, bundle, caching,
  console/network hygiene, and collision/overflow behavior;
- current Chromium, Firefox, and WebKit support.

Out of scope unless separately justified and authorized: changes to game rules,
answer generation/reveal, scoring, evidence, prices, rewards, ratings,
matchmaking, persistence envelopes, settlement, word lists, real player data,
the locked shell, default branch, or Production.
