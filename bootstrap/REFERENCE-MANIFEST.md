## Image intake procedure

For each later attached image:

1. inspect the complete image;
2. copy it only into the approved bootstrap reference area;
3. record original path or URL, SHA-256, dimensions, provenance, and date;
4. record concrete observations for composition, density, typography,
   interaction, motion, responsive behavior, and material treatment;
5. classify it as binding, directional, or mood-only;
6. identify any conflict with accessibility or functional contracts.

Historical Amordle Concept Gallery images and current-site screenshots are
explicitly excluded unless a later user request names an individual image as a
new reference.
